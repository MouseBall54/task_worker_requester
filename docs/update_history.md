# IPDK_plus 업데이트 이력

## 문서 관리 지시사항

1. 새 버전은 이 지시사항 바로 아래에 최신순으로 추가한다.
2. 이미 작성된 버전 항목은 삭제하거나 내용을 수정하지 않는다.
3. 버전은 앱과 설치 프로그램에 적용된 `YY.M.D` 값을 그대로 사용하고, 배포일은 한국 표준시 기준 `YYYY-MM-DD`로 기록한다.
4. 변경 내용은 이전 배포 버전과 비교해 사용자가 체감하거나 운영에 영향을 주는 검증된 사항만 간단히 작성한다.
5. 기존 기록의 오류를 발견하면 원문을 고치지 말고 최신 항목에 정정 사유와 대상을 별도로 남긴다.
6. 아직 구현 또는 검증되지 않은 계획은 업데이트 이력에 포함하지 않는다.

## 26.8.5 - 2026-08-05

이전 버전: `26.7.9`

- 하나의 폴더와 이미지에 여러 Recipe를 지정하고, 이미지와 Recipe 조합별로 독립된 요청을 생성할 수 있게 개선했다.
- 폴더 추가 시 선택한 Recipe, Action, Priority를 작업 정보에 보존하고 Recipe별 선택 경로를 개별 행으로 표시하도록 변경했다.
- 대규모 작업을 SQLite에 저장하고 활성 폴더 제한, 청크 단위 메시지 생성, queue/inflight 상한, 상세 목록 지연 로딩을 적용해 수십만 건 대기 시 메모리 사용을 제한하도록 개선했다.
- 중단된 작업의 스캔, 미발행 요청, 결과 polling을 다음 실행에서 이어서 처리할 수 있도록 복구 흐름을 보강했다.
- Recipe 선택창과 Priority 배치·화살표, 선택 경로 행 높이와 겹침 문제를 정리해 기본 창 크기에서도 안정적으로 표시되도록 개선했다.
- 폴더 트리에서 깊은 폴더를 직접 선택한 뒤 가로 스크롤이 다시 맨 왼쪽으로 돌아가던 문제를 수정했다.
